# Fake-News-Predictor

This project detects whether a news article is Fake or Real using:

- Logistic Regression
- TF-IDF Vectorizer
- Flask Web Application
- GPT-2 based Text Summarization

## Features
- Fake/Real prediction
- Confidence score
- Suspicious word highlighting
- AI-generated summary

## Technologies Used
- Python
- Scikit-learn
- Flask
- Transformers
- HTML/CSS

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run:
   python app.py
